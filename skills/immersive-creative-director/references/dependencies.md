# Dependency compatibility

Immersive Creative Director is the synthesis owner; installed skills are replaceable specialist implementations. Before relying on one, discover it dynamically, read its complete current instructions, and verify that its actual outputs still satisfy this contract. A matching name is not compatibility.

## Required capability contracts

| Capability | Required output/behavior | Boundary |
|---|---|---|
| Grilling | Complete decision-tree frontier, exact question format, wait, recompute, user confirmation | Cannot be replaced by ordinary clarifying questions |
| Domain Modeling | Term conflict, edge-case, glossary, and decision discipline during intake | Does not invent project facts |
| Impeccable | Substantive visual judgment and anti-generic critique | Immersive corpus remains taste authority |
| Design DNA | Transferable system/mechanism separated from recognizable identity | Never copies a reference surface |
| Scrollcraft | Journey, feeling curve, peak, grammar, signature move, score, input, responsive/reduced motion, chronology | Must pass [scrollcraft-adapter.md](scrollcraft-adapter.md) |
| Prototype | Throwaway, question-led UI or logic variants with genuinely different answers on a named divergence axis | Conditional: only when an unresolved design question cannot be settled responsibly in stills or prose; only the approved answer enters production |
| Design Loop | Fresh rendered capture → critique → revision loop with nested Impeccable | Runs only after build/refinement authority |
| Filipe Flow | One bounded outer execution dispatch | Cannot redefine the approved premise |
| Watch | Complete transcript, commercial exclusion/resumption, timestamped procedure evidence | Video frames have no website-taste authority |
| Browser Proof | Exact rendered browser chronology and interaction proof | Source inspection is supporting evidence only |
| Actual Surface Verifier | Distinct deployed/exported/native surface proof when applicable | Never duplicates Browser Proof for one surface |

Prototype, Poteto, image generation, GSAP/framework, performance, accessibility, and other specialists remain predicate-driven. Missing optional capability changes the route; missing required capability blocks its dependent phase.

## Compatibility record

Record for every selected dependency: resolved skill name/path/version or content hash; required predicate; complete workflow loaded; adapter/conflict result; exact outputs; completion evidence; and verdict. Recheck whenever the installed file changes, a behavior test fails, or the direction run advances to a phase owned by that capability.

Run `python3 scripts/validate_dependencies.py` for local presence evidence. It cannot prove workflow compliance; the direction run and behavioral tests prove that. Do not pin a personal filesystem location in the project artifact or silently install/upgrade a dependency.
