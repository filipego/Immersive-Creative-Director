# Durable website motion evidence

Website motion has three evidence layers. Never make a stronger claim than the layer supports.

1. **Live source URL:** authoritative for current timing, easing, input mapping, hold/release, reversal, and interactive feel. Reopen it in the Codex in-app Browser whenever a selected mechanism or disputed judgment depends on those qualities.
2. **Written chronological record:** authoritative for the observed pass captured in `reference-corpus.md`, including input method, scene causality, transitions, page modes, and stated limitations.
3. **Local chronological strip:** durable evidence of composition/state progression when a live source changes or disappears. Each row below records the exact source-frame order used. A strip proves visible sequence and topology change; it does not prove exact timing, easing, or input response.
